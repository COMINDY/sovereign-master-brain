# 🎯 ยิงตรงเข้า API แฟ้ม "Top Performing" ของ Shopee Dashboard 100%!

> **จากรูปภาพหน้าจอ Shopee Affiliate Dashboard ที่มึงส่งมา**:  
> มึงเปิดค้างอยู่ที่แท็บสีส้ม **`Top Performing`** 
> (ที่มีสินค้าตัวท็อปอย่าง หมอนโคลด TOTORI 9%, ข้าวกล้องหอมมะลิ 9%, เสื้อคาร์ดิแกน Paloy 12%, น้ำยายางดำ 11%, แปรงฟัน SYSTEMA 8%)

---

## 🛠️ สิ่งที่กูแก้ไขในระบบ `auto_harvester.py`:

1. **เจาะตรงพารามิเตอร์ `list_type=3` (Top Performing Tab)**:  
   - ปรับโค้ด Playwright ใน `auto_harvester.py` ให้ยิงดึงสินค้าตรงเข้าแฟ้ม **`list_type=3`** ซึ่งเป็น API เบื้องหลังของแท็บ **Top Performing** ในรูปหน้าจอมึงแบบเป๊ะๆ 100%!
2. **ดึงสินค้า Top Performing 200 รายการจุใจ**:  
   - สกัดสินค้าที่ทำยอดคอมและยอดขายสูงสุดในแท็บนี้ มาเรียบเรียงลงฐานข้อมูล
3. **สั่งรัน Playwright Engine สดๆ**:  
   - กำลังดึงสินค้า Top Performing จากหน้าจอของมึง เซฟลง `data/affiliate_products.json` และสั่ง `git push` เข้า Vercel ทันที!

# 🎥 Green Code YouTube Channel Master Index & Neural Network AI Trading

> **ดรรชนีความรู้และสถาปัตยกรรม AI จากช่อง YouTube `@Green-Code`:**
> รวมแนวทางการสร้าง AI Trading Bot, การเทรน Neural Networks (PyTorch / TensorFlow) และ Machine Learning Pipelines สำหรับทำนายตลาดด้วย Python

---

## 🏛️ 3 เสาหลักเทคโนโลยีในช่อง Green Code (@Green-Code)

### 1. Neural Networks & Deep Learning for Trading:
- การใช้ **PyTorch** และ **TensorFlow/Keras** ในการสร้างสถาปัตยกรรม Neural Networks (เช่น MLP, LSTM, GRU) เพื่อเรียนรู้โครงสร้างอนุกรมเวลา (Time-Series Market Data)
- การคำนวณ **Loss Functions** และการใช้ Optimizer (Adam, SGD) เพื่อให้โมเดลคาดการณ์ทิศทางราคาได้แม่นยำยิ่งขึ้น

### 2. Python Feature Engineering Stack:
- การเตรียมข้อมูลด้วย `pandas`, `scikit-learn`, และ `numpy`
- การสร้างตัวแปรป้อนเข้าโมเดล (Feature Matrix) เช่น Normalized Returns, Indicator Differences, Volatility Ratios

### 3. Predictive Classification & Entry Filters:
- การใช้โมเดลทำหน้าที่เป็น **Binary Classifier (0 หรือ 1)** เพื่อให้สัญญาณอนุมัติเปิดออเดอร์เฉพาะจังหวะที่มีความน่าจะเป็นสูง
- การวัดผลด้วยค่า **Accuracy, Precision, Recall, และ ROC-AUC** ก่อนนำไปรันจริง

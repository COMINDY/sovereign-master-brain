# 🎯 ปรับโครงสร้างดึงสินค้าขายดี 50 อันดับแรกของทุกหมวดหมู่ + เปลี่ยนชื่อค่าคอมพิเศษ 100%!

> **โจทย์มึง**:
> *"มึงเอา 50 อันดับแรกของแต่ละอันที่ขายดีที่สุดมาเลยสัส ทั้งหมด (สินค้าขายดี, เครื่องใช้ในบ้าน, คอมพิวเตอร์และแล็ปท็อป, มือถือ และ แท็บเล็ต, กลุ่มผลิตภัณฑ์เพื่อสุขภาพ, ความงามและของใช้ส่วนตัว) ยกเว้น ค่าคอมพิเศษ ที่มึงต้อง เปลี่ยนชื่อมัน"*

---

## 🛠️ รายละเอียดการอัปเดตระบบ:

1. **ดึงสินค้าผ่าน API แยกรายหมวดหมู่ (Category Endpoints)**:
   - สั่งให้ `auto_harvester.py` ยิง API ตรงเข้าทุกแท็บหลักของ Shopee Affiliate:
     - `list_type=3` (**สินค้าขายดี / Top Performing**)
     - `cate_id=100636` (**เครื่องใช้ในบ้าน**)
     - `cate_id=100013` (**คอมพิวเตอร์และแล็ปท็อป**)
     - `cate_id=100014` (**มือถือ และ แท็บเล็ต**)
     - `cate_id=100631` (**กลุ่มผลิตภัณฑ์เพื่อสุขภาพ**)
     - `cate_id=100630` (**ความงามและของใช้ส่วนตัว**)
2. **คัดกรอง 50 อันดับแรกที่ขายดีและคอมมิชชั่นสูงที่สุดประจำแต่ละหมวด**:
   - `process_raw_offers.py` จะจัดกลุ่มสินค้าเข้าตามหมวดหมู่ตรงเป๊ะ และตัดเอา **50 อันดับแรก** ของแต่ละหมวดเข้าสู่ฐานข้อมูล
3. **เปลี่ยนชื่อ/ถอดคำว่า "ค่าคอมพิเศษ" (Renamed Commissions XTRA)**:
   - จัดสรรสินค้าจากแท็บค่าคอมพิเศษ กระจายจำแนกตามชนิดสินค้าเข้าหมวดหมู่จริงทันที!

## 🧬 Key Code Architecture: ForexTradingEnv (PPO RL)

```python
# trading_env.py — ForexTradingEnv key design
class ForexTradingEnv(gym.Env):
    # Actions: 0=HOLD | 1=CLOSE | 2+=OPEN(direction, sl_idx, tp_idx)
    # SL_OPTS = [5, 10, 15, 25, 30, 60, 90, 120]  # pips
    # TP_OPTS = [5, 10, 15, 25, 30, 60, 90, 120]  # pips
    
    # Friction modeled:
    # - spread_pips (round-trip cost)
    # - commission_pips
    # - max_slippage_pips (random 0..max)
    
    # Reward shaping:
    # - realized PnL in pips on close
    # - unrealized delta weight (0.02) while holding
    # - open_penalty_pips (0.5) per open
    # - time_penalty_pips (0.02) per bar in trade
    
    # Observation:
    # - rolling window of feature columns (30 bars)
    # - + [position, time_in_trade, unrealized_pnl_pips]
    
    # Anti-overfit:
    # - random_start=True (random episode start)
    # - 80/20 time split (train/test)
```
